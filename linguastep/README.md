# LinguaStep

Prototype de formation aux langues professionnelles : test adaptatif A1 → C2
et parcours par niveau, pour six langues (anglais, espagnol, allemand, italien,
portugais, français FLE).

Application statique : ouvrir `index.html` ou utiliser la version publiée par
GitHub Pages. Aucune donnée n'est envoyée : la progression reste dans le
navigateur (localStorage), avec export/import JSON.

Contenu de démonstration, non certifiant, à relire par des locuteurs natifs
avant diffusion.
